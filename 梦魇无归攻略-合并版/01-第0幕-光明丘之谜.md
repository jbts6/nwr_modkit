# 第 0 幕 · 光明丘之谜

> 返回[总览](./README.md) · 上一章：[基础系统](./00-基础系统.md)

**三个称号**，正常流程即可全收（10 分钟正常够用，摸鱼除外）。

## 开局

- 领取金字塔入口各种礼包，对话博士接取支线任务。
- 左下篝火互动可恢复满状态一次。
- 左上和右上闪光点有**宝石碎片**和**奇异之物**（怕时间不够可出来时再领）。
- 调整装备：特殊道具里开启装备材料包和冠军庆典礼包，装备-推荐一键变装，属性-分配加一点敏捷。
- 随身商店买《异常生命见闻录》（怪物图鉴），以备不时之需。

## 金字塔内部

- 闪光点安装摄像机，转一圈捡到 3 个狗牌（可卖可收藏，多周目有剧情伏笔）。
- 正上方进去调查石棺，获得**魔能石**和**样本**（样本为蚊子肉属性药，可继承到 5 周目；魔能石第 8 世界还有用）。
- 本世界遇到怪物全程平 A 即可。
- 上楼，魔能石给石柱充能点亮，出现隐藏门。
- 下楼（点两次），转角遇到爱，击败鬼魂后，先往上走，**不要踩深色砖块**。
- 该充能充能、该安摄像机安摄像机，上三楼后返回往左下楼梯走。
- 遇见喵喵（抱走抱走），达成成就"快人一步"。

## 特长选择

- 见[基础系统](./00-基础系统.md)——力量「人」/体力「鳞」/精神「羽」/敏捷「毛」，按取消得隐藏特长**全能**。
- 建议 1 周目全能（双倍积分+50% 经验），2 周目体主，3-5 周目随意。

![特长选择界面](./images/ta_chang_select.jpg)

## 收尾

- 特长选择完毕，装备上新的传承，了解一下职业技能。
- 回到深色砖块区域把砖块踩了，掉进陷阱，搜个尸。
- 上楼出金字塔找博士交任务，获得 2000 积分 + 世界树之叶，往下结束第 0 幕。
- 探索度 100%，积分 +3000，功勋 +5，获得**解牛刀**（分解道具，很重要）。
