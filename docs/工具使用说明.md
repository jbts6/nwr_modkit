# 梦魇：无归 Modkit 工具使用说明

本文只写当前可用路线：存档编辑器、存档编解码、数据密钥复验、数据 JSON 提取/回包。

## 启动存档编辑器

在游戏根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\launch-save-editor.ps1
```

默认打开：

```text
http://127.0.0.1:5176/
```

如果端口被占用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\launch-save-editor.ps1 -Port 5177
```

如果只启动服务不自动打开浏览器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\launch-save-editor.ps1 -NoOpen
```

## 存档位置

常见位置：

```text
www/save/
```

文件示例：

```text
file1.rpgsave
file2.rpgsave
global.rpgsave
config.rpgsave
```

编辑前建议手动备份整个目录：

```powershell
Copy-Item .\www\save .\www\save_backup -Recurse
```

## 存档格式说明

当前游戏存档没有 AES 密钥，也没有 HMAC 校验。格式是：

```text
LZString Base64 -> zlib deflate -> JSON
```

对应工具：

```text
nwr_modkit/tools/save-codec.mjs
```

因此编辑器显示的是原生 JSON 结构，不需要额外填写密钥。

## 复验数据密钥

如果要重新确认 `www/data/*.json` 的数据密钥，执行：

```powershell
node .\nwr_modkit\tools\probe-data-key.mjs --game-root .
```

当前已验证参数：

```text
algorithm: aes-192-cbc
password:  6f03e16e201226059d4aaa5e1950da4a
salt:      2023/3/19
keyHex:    eda0337069573a14c302c58324416304580b3a7e515133ab
ivHex:     01010101010101010101010101010101
```

脚本会直接解 `www/data/System.json`、`Actors.json`、`MapInfos.json`。不需要启动游戏。

如果要指定采样文件：

```powershell
node .\nwr_modkit\tools\probe-data-key.mjs --game-root . --samples System,Skills,Items
```

如果要用显式 key 复验：

```powershell
node .\nwr_modkit\tools\probe-data-key.mjs --game-root . --key-hex eda0337069573a14c302c58324416304580b3a7e515133ab
```

## 重新抓取 scrypt 调用

如果要确认密钥不是手写猜测，可以重新跑运行时探针。

先刷新 harness：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\setup-runtime.ps1 -GameRoot .
```

删除旧结果：

```powershell
Remove-Item .\nwr_modkit\runtime\save-harness\probe-result.json -Force -ErrorAction SilentlyContinue
```

启动隐藏探针窗口并等待结束：

```powershell
$h = (Resolve-Path .\nwr_modkit\runtime\save-harness).Path
Start-Process -Wait -FilePath "$h\Game.exe" -WorkingDirectory $h
```

查看关键调用：

```powershell
rg -n "scryptSync|createDecipheriv|6f03e16e201226059d4aaa5e1950da4a|2023/3/19|eda0337069573a14c302c58324416304580b3a7e515133ab|aes-192-cbc" "$h\probe-result.json"
```

应能看到两类记录：

```text
scryptSync(password, salt, 24)
createDecipheriv("aes-192-cbc", key, iv)
```

这说明密钥来源是游戏加载阶段实际调用的 Node crypto，不是离线脚本硬猜。

## 数据 JSON 提取

提取 `www/data/*.json` 到明文目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\extract-data.ps1 -GameRoot .
```

默认输出：

```text
nwr_modkit/output/extract/data/
```

报告文件：

```text
nwr_modkit/output/extract/data/_extract-report.json
```

## 数据 JSON 回包

先修改：

```text
nwr_modkit/output/extract/data/*.json
```

再加密输出：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\encrypt-data.ps1
```

默认输出：

```text
nwr_modkit/output/repack/data/
```

报告文件：

```text
nwr_modkit/output/repack/data/_repack-report.json
```

这个命令不会自动覆盖原游戏 `www/data`。要替换时应先备份原文件。

## 单独提取存档 JSON

如果只想把所有 `.rpgsave` 解到输出目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\extract-saves.ps1 -GameRoot .
```

默认输出：

```text
nwr_modkit/output/extract/save/
```

## 检查小黑屋判定

如果读档后被传送到 `监禁小屋`，可以先跑诊断：

```powershell
node .\nwr_modkit\tools\diagnose-prison-checks.mjs --game-root .
```

指定其它存档：

```powershell
node .\nwr_modkit\tools\diagnose-prison-checks.mjs --save .\www\save\file1.rpgsave
```

该脚本会检查公共事件里的“小黑屋”阈值，包括：

```text
至尊魔戒 >= 3
传说的灵魂结晶 >= 200
红色萃取精华 >= 200
橙色萃取精华 >= 80
金钱 >= 9000000
功勋变量 >= 5000
浮世绘卷 >= 2
针剂进化次数 >= 99
全面进化针剂 >= 99
角色 #16 在队伍中且缺物品 #49
角色 #16 在队伍中且缺赤炎魔杖 #59
立花野子 #57 在队伍中且缺东乙青木橛 #819
圣女-贞德 #48 在队伍中且缺圆润的珠子 #73
立花野子 #57 在队伍中且缺物品 #101
角色 #31 在队伍中且缺物品 #860
```

如果输出 `Hits: none`，说明当前存档没有命中已知离线阈值；剩下可能是运行时才计算的角色参数判定。

当前静态枚举范围包括公共事件、地图事件、战斗事件、物品/技能效果、事件页条件和事件脚本命令。已确认没有额外的物品/技能效果调用，也没有脚本命令手写 `$gameSwitches.setValue(520)` 或 `reserveTransfer(695)`。

存档编辑器也内置了同一套护栏：

```text
小黑屋护栏
  刷新检测
  一键修复
```

导出 `.rpgsave` 前会重新检查已知硬阈值。若命中风险，编辑器会拒绝导出，并提示先修复或手动调低数值。

一键修复会处理：

```text
清除 Switch 520【破坏规则惩处】
至尊魔戒压到 2
传说的灵魂结晶压到 199
红色萃取精华压到 199
橙色萃取精华压到 79
金币压到 8999999
功勋压到 4999
浮世绘卷压到 1
针剂进化次数压到 98
全面进化针剂压到 98
角色 #16 缺物品 #49 时补 1 个物品 #49
角色 #16 缺赤炎魔杖时补 1 个赤炎魔杖 #59
立花野子缺东乙青木橛时补 1 个东乙青木橛 #819
圣女-贞德缺圆润的珠子时补 1 个圆润的珠子 #73
立花野子缺物品 #101 时补 1 个物品 #101
角色 #31 缺物品 #860 时补 1 个物品 #860
```

`CommonEvent 344` 的 `actor(2).param(9)` 是运行时计算值，编辑器会提示但不能离线完全证明。

## 单独重新编码存档

如果已经有明文 JSON，并想重新生成 `.rpgsave`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\nwr_modkit\tools\encrypt-saves.ps1
```

默认读取和输出由脚本内约定控制；正式覆盖前请先检查 `nwr_modkit/output` 里的结果。

## 常用环境变量

可选设置游戏根目录：

```powershell
$env:NWR_GAME_ROOT = "D:\Games\Nightmare without return"
```

可选设置 npm registry：

```powershell
$env:NWR_NPM_REGISTRY = "https://registry.npmmirror.com"
```

旧的 `DQ2_GAME_ROOT`、`DQ2_NPM_REGISTRY` 仍保留兼容，但新文档统一使用 `NWR_*`。

## 常见判断

如果问“存档密钥是什么”：当前没有存档密钥。

如果问“数据 JSON 密钥是什么”：是 `aes-192-cbc`，key 为：

```text
eda0337069573a14c302c58324416304580b3a7e515133ab
```

如果问“素材加密 key 是什么”：解密后的 `System.json` 给出：

```text
c8837b23ff8aaa8a2dde915473ce0991
```

这三者不是同一个东西。
