# 多周目与新周目指南

> 本文基于游戏提取数据(`output/extract/data`)的静态分析写成,引用处标注了地图/公共事件(CE)编号,可逐条回查。少数结论受插件加密限制,已明确标注"待运行时验证"。

## 一、周目系统总览

- 周目数记录在**变量 312「梦魇周目数」**,只在通关事件中 +1。
- 开启新周目依赖 New Game+ 插件(YEP_X_NewGamePlus + GALV_NewGamePlus):通关后**存一档,返回标题,该存档位的"读取"会变成"新周目"**,点击即进入下一周目。
- 游戏文本明确警告:**请不要用 1 号存档位保存**(Map758)。
- 全部事件中没有任何分支读取变量 312——周目之间的内容差异全部通过**插件的继承开关/物品**实现,而不是"周目数判断"。数值压力来自独立的难度系统(见第七节)。

## 二、三条开启新周目的路线

| 路线 | 位置 | 说明 |
|---|---|---|
| 周目 Boss 路线 | 四象塔中转(Map006)找接引人**若不群**(CE239,战斗 troop 371) | 完成当前周目所有任务后开启。胜利给物品 460(多周目凭证,触发任务完成度加成)并执行 `EnableNewGamePlus`,SW480 置 ON |
| 普通结局路线 | 面具男最终位置二(Map747-ev4) | 达成**结局一「困兽」**,周目数+1,`Galv.NEWGP.activate()` |
| 真结局路线 | 焦土(Map758-ev2) | **梦魇难度**击败最终 Boss 面具男,达成**真结局「自由」**,周目数+1。额外奖励:挑战点+30、成就积分+100、梦魇 Boss 击杀数+5、幻化"头戴面具的人"、特长转职书(1089),SW680 置 ON |

> CE239 的对话接线在加密的自定义界面里,静态无法定位按钮,但事件文本自述了条件:"检测到你已完成当前周目的所有任务"。

## 三、继承与清零清单

游戏原文(Map747/758/CE239):"你的装备、物品、金钱、**可装备的**天赋技能将会继承到新周目中,其他的均无法继承"。

**继承**:

- 装备(进入新周目瞬间会强制全部卸下,进包)、物品、金钱
- 可装备的天赋技能
- 传承奖励物品(完美继承,见第四节)
- 插件配置清单内的部分开关/变量(清单加密在 plugins.js,**待运行时验证**,可用修改器 `runtime.inspect` 查看 `Galv.NEWGP` 对象)

**不继承(进新周目前处理掉)**:

- **功勋值**(变量 29,清零)
- **挑战点**(变量 320)——四象塔的兑换商店"群"明说"挑战点多周目不继承,请及时兑换"(Map006)
- **成就积分**(变量 313)——可在空间休闲区(Map098)兑换血腥制式装备;文本说"影响很小,可无需消耗"
- **个人仓库里的所有道具**(Map015)——仓库是"周目粉碎机":想带走的取出,不想要的放进去让它下周目消失
- 声望、好感度、各幕任务进度等普通变量(除插件清单外)
- 打怪/钓鱼统计、周目内领取过的每周目福利次数

## 四、传承奖励(五选一)

通关事件中选择一项,物品 551-555,进入新周目后使用,当前周目用了就带不过去:

| 物品 | 效果(按事件文本) |
|---|---|
| 551 力量传承 | 力量提高 20%(另一处文本写作 10% 吸血,以游戏内实际为准) |
| 552 体质传承 | 10% 体质 / 5% 体力 / 200% 仇恨(另一处:10% 体质加成) |
| 553 精神传承 | 4% 护盾转化(另一处:10%) |
| 554 敏捷传承 | 每三下攻击 2% 伤害 |
| 555 全能传承 | 经验获取 +20%,四维属性 +4% |

## 五、进新周目前的检查清单

1. **个人仓库**:取出所有想保留的道具(Map747/828 结局事件也会临时开一次仓库让你取)。
2. **挑战点**:在四象塔商店(若不群处)兑换干净。
3. **成就积分**:想花就在空间休闲区(Map098)换血腥制式装备。
4. **选好传承奖励**。
5. **卸下装备再选传承**(Map575-ev14 作者提示):转职/传承瞬间有微小概率吞掉装备上镶嵌的刻印和宝石;作为补偿会送无限之刻印×1。一周目大量吃过成长型药剂的,补偿全面进化针剂×2(=400 功勋)。
6. **宝石吞档 BUG 规避**(Map575-ev16 作者原话):进入新周目后先**存档并完全退出游戏一次,再读档进入**,之后打宝石才不会被第一次存读档吞掉。
7. 存到**非 1 号档**,回标题点"新周目"。

## 六、多周目内容变化逐条

### 1. 四象塔逐周目开塔(净白塔 Map005 / 四象塔中转 Map006)

- 1 周目:北之玄武(水)·火之塔朱雀需通关一周目·2 周目:南之朱雀·3 周目:西之白虎·4 周目:东之青龙
- 青龙塔说明:"三周目之后青龙的能力不再增长"——即 4 周目开青龙,5 周目起不再变强
- 每 10 层遇一只圣兽,击败**必定**掉传说级打造图纸 + 传说的灵魂结晶
- ⚠️ **传说的灵魂结晶(物品 656)持有 ≥200 会触发 CE337 终身监禁**(禁存档/传送小黑屋)。四象塔反复刷圣兽时注意数量,修改器小黑屋护栏里有这条(安全值 199)
- 新周目后:挑战点商店重新补货、多周目购买权限提升(Map006)

### 2. 规则之力(第一地点 Map046-ev11)

| 阶 | 效果 | 触发(文本原话) |
|---|---|---|
| 一阶 | 力量/精神 +10%,暴击率 +10%,抗暴击 +10%,体力上限 +10% | "将经历多周目" |
| 二阶 | 体力/法力上限 +20%,力量/精神 +20%,抗暴 +15%,暴击 +20%,敏捷 +5% | "更多周目" |
| 三阶 | 体力/法力上限 +35%,力量/精神 +30%,抗暴 +20%,暴击 +30%,敏捷 +10% | "非常多周目及以上" |

### 6. 特定周目补偿/解锁

- **多周目序章变化**:真·法老王陵寝内出现**喵喵(恶魔之手,角色49)**与仆人**贾正经**的重逢入队事件(贾正经带被动"摸金校尉":三周目后队伍有概率获得特殊制造图纸)。一周目实测无此事件(显隐由加密插件控制);贾正经的一周目正式入队点在后续幕的小监狱救援(Map230)。
- **二周目起**:八苦命境开启(装备合成处 Map024)
- **三周目**:未获得"樱的传承"的契约者获得补偿 + 东方神话世界之核(交易广场 Map019);交易广场开放**一次**紫色武器平换(减少多周目紫武合成消耗)
- **四周目**:击败死亡塔 Boss 才掉"传承之石"打造图纸;传承之石兑换神陨之魄(Map019)
- **一周目限定**:东北小村(Map063)命运通道,可传回梦魇空间——错过不再有

### 7. 五周目 = 终极难度周目 → 无限周目

- CE475「身世」:"你进入了终极难度的周目,五周目……"
- 五周目通关后(Map828 某处小屋)开启**无限周目**:所有内容以五周目为准不再变化;赠礼神陨之魄×2、难度"插件-终极考验"、幻化"紫星"(啾啾专属)
- 地狱难度说明(CE293):多周目的地狱难度**只有时间限制,怪物属性无提升**

## 七、难度系统(与周目数无自动联动)

- 难度由 Vitsuno_Difficulty 插件管理,变量 236「游戏难度等级」;插件参数倍率:难度 1 全属性 0.3 倍,难度 2 标准 1.0,难度 3 约 1.5/1.6,难度 4 起 2.0(掉率同步缩放)
- 事件中没有"周目数→难度"的强制联动;5 周目的"终极难度周目"是唯一例外(经由结局事件)
- 变量 236 没有事件写入点(全部走插件界面),想改难度直接改游戏内难度设置,或用修改器写变量后**待运行时验证**是否即时生效

## 八、与修改器配合的注意事项

| 项 | 变量 | 说明 |
|---|---|---|
| 梦魇周目数 | 312 | 只影响统计显示,不影响内容 |
| 挑战点 | 320 | 本周目有效,不继承,想刷随便改 |
| 成就积分 | 313 | 同上 |
| 梦魇 Boss 击杀数 | 317 | 统计量 |
| 游戏难度等级 | 236 | 插件管理,事件不读写 |
| 功勋 | 29 | ⚠️ 上限 4999(≥5000 触发 CE341 终身监禁);新周目清零,设计上就是"提前换成物品" |

- 想安全试错剧情判定点:`~` 快存 + F8 快读,配合游戏倍速很舒服。
- 四象塔刷圣兽时盯紧"传说的灵魂结晶"数量(≤199)。
- 修改器小黑屋面板会实时检测这些阈值,拿不准就刷新一次。
