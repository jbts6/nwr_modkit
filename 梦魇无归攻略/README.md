## 装备品质

> 蓝色 ＜ 绿色 ＜ 银色 = 暗金 ＜ 金色剧情 ＜ 血腥 ＜ 橙色传说 ＜ 紫色

- **蓝色、绿色、暗金、血腥**的装备或技能分解 = **蓝色、绿色、金色、红色**的萃取精华 ×1
- **银色剧情** = 金色 ×1 或 2
- **金色剧情** = 金色 ×5

## 称号品质

> 蓝色 ＜ 绿色 ＜ 暗金 ＜ 紫色

- 蓝色、绿色、红色、紫色称号碎片 ×2

## 梦魇空间（每幕通关后的中转站）

### 休闲区
- **锦鲤抽奖**：每通关一幕可抽一次，随机奖励 6~666666 积分，存读档刷最高收益。
- **章鱼保罗**：回收高级钓点钓到的道具（飞翔荷兰人号×4／安妮女王复仇号×4）兑换奖励，随机获得红/绿精粹或功勋道具（艾克斯进化剂、赌斗之券、10w 积分等）。
- **道具商人**：购买毒烟筒×50、旋转飞盘×50、太平文疏-雨×30、神袛之符×1。
  - 无法使用技能（冷却或沉默）时，除普攻外可用道具打伤害。
- **功勋商人**：出售徽章、结晶体等，购买真魔剑配方、赌斗之券×1、异常生命见闻录。
- **训练场**：开启训练人偶，主角和樱等级 +1。
- **黑荆**：18000 积分（和十八相送）。
- **烈山**：赌斗（银色钥匙或圆润珠子），胜利奖励 9000 积分，离子炮直接秒。
- **克尔娜**：赌斗（输了全属性 -10），胜利奖励奇异结晶体×9，雷光拳+离子炮。
- **神秘商人**：每通关一幕更新一次交易。2w 积分换宝石袋，火腿肉换火之刻印，圆润的珠子换光明庇护。
- 赌斗、神秘商人后面通关世界会刷新掉，**前面不做就没了**。

### 随身商店 / 锻造台
- 道具-特殊-随身商店：随身买卖、购买精粹。
- 随身锻造台：合成装备（如真·魔剑阿波菲斯）。

### 传送
- 大厅（上）为下一个世界传送处。
- 再上面的传送处可花积分返回通关过的第一、四、七、十的世界（例如第一幕豪森堡传送法阵可刷暗怪，换蓝绿精粹、传说灵魂结晶，后期很缺）。

## 常用战斗节奏（老规矩）

> 攻略中反复出现的思路，打 BOSS 前通用：

1. 磕药补满状态。
2. 喝白兰地、龙舌兰（三回合 +20% 体质、力量）。
3. 打上医用、军用绷带（3~5 回合恢复体力）。
4. 辅助技：**缄默**（吸蓝、50% 概率沉默）、**巫蛊术**（持续吸血）、**诅咒**（削弱）、**精神控制**；群体道具：**太平文疏-雨**（秒杀精灵类）、**旋转飞盘 / 镔铁回旋镖**（道具伤害）、**毒烟筒**（中毒）。
5. 击杀 BOSS 后开钥匙 → 分解 → 做套装。

### 关键道具掉落
- 老山参：群体恢复 40%
- 医疗包、灵芝：单体恢复 70%
- 上善若水：全员复活，等级 +1
