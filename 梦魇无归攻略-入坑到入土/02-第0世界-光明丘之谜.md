# 第 0 世界 · 光明丘之谜

> 返回[总览](./README.md) · 上一章：[前言与基础](./01-前言与基础.md)

**有三个称号可获得**，正常流程即可全收（10 分钟正常够用，摸鱼除外）。

## 流程

- 先在金字塔入口领取各种礼包，对话博士接取支线任务。
- 左下篝火互动可恢复满状态一次。
- 左上和右上闪光点有**宝石碎片**和**奇异之物**（怕时间不够可出来时再领）。
- 调整装备：在特殊道具里开启**装备材料包**和**冠军庆典礼包**，装备-推荐一键变装，属性-分配加一点敏捷。
- 在随身商店买本《异常生命见闻录》（怪物图鉴），以备不时之需。

## 金字塔内部

- 闪光点安装摄像机，转一圈捡到 3 个**狗牌**（可卖可收藏，多周目有剧情伏笔）。
- 正上方进去调查石棺，获得**魔能石**和**样本**（样本为蚊子肉属性药，可继承到 5 周目）。
  - 本世界遇到怪物全程平 A 即可。
  - 魔能石第八世界还有用。
- 上楼，魔能石给石柱充能点亮，出现隐藏门。
- 下楼（点两次），转角遇到爱，击败鬼魂后，先往上走，**不要踩深色砖块**。
- 接下来该充能充能、该安摄像机安摄像机，上三楼后返回往左下楼梯走。
- 遇见喵喵（抱走抱走），达成成就"快人一步"。

## 特长选择（决定人物的主被动技能）

| 特长 | 提问答案 |
|------|---------|
| 力量 | 人 |
| 体力 | 鳞 |
| 精神 | 羽 |
| 敏捷 | 毛 |

- 按取消，获得隐藏特长——**全能**。
- 特长详细参考：[开局选项和五种特长介绍](https://www.taptap.cn/topic/21000764)。

**建议**：
- 1 周目**全能**（双倍积分 + 额外 50% 经验，适合积累资源）。
- 2 周目**体主**（无人屠前抗压）。
- 3-5 周目随意。
- 本攻略采用 **1-5 周目依次为：全、体、力、精、敏** 的打法。

**加点建议**：梦魇难度随机应变！本游戏可随时自由洗点。小兵战可点满敏捷，BOSS 战需要根据 boss 属性值、技能性质和己方人员配置加点，一周目比较常用**加体质**，少量 boss 加**感知**。

## 收尾

- 特长选择完毕，装备上我们的新传承，顺便了解一下职业技能。
- 回到深色砖块区域把砖块踩了，掉进陷阱，搜个尸。
- 上楼出金字塔找博士交任务，获得 2000 积分 + 世界树之叶，往下结束第 0 幕。
- 探索度 100%，积分 +3000，功勋 +5，获得**解牛刀**（分解道具，很重要）。
